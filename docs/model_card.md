# 模型卡（Model Card）—— FeynmanForge

| 项 | 内容 |
|---|---|
| 系统名 | FeynmanForge |
| 任务 | 符号回归（从样本 `(X, y)` 恢复人类可读的解析表达式） |
| 方法 | Age-Fitness Pareto 遗传编程（Schmidt & Lipson, 2011） |
| 作者 | 晨星（CJX0712） |
| 版本 | v0.1.0 |
| 许可 | MIT |

## 1. 预期用途

- **适用**：从观测数据中挖掘简洁数学关系（物理定律发现、工程经验公式、可解释代理模型）。
- **不适用**：需要概率校准/不确定度量化的场景；超大规模高维（>~6 变量）稠密数据的实时拟合。

## 2. 能力与局限（基于 21 函数基准）

### 稳定恢复的类别（R² ≥ 0.9999，精确恢复）
- 单变量代数/超越：`lin1, quad1, cubic1, sin1, sqrt1` 等；
- 二变量多项式/乘积：`poly2d, prod2, poly3mix` 等；
- 部分高斯/指数结构：`gauss2d, exp1`（高保真，接近精确）。

### 高保真但未达严格阈值的类别（诚实负例）
- `log1, rat1, rat2`：结构基本命中，常量/深层有理式精度略欠；
- `lin3`（三变量线性）：近似可达 R²≈0.975，仍有冗余项；
- `poly4mix`：高阶多项式，需更大预算。

### 明确未恢复（记录为失败案例，见 `benchmark.json.failures`）
- `dist2, trig2, feynman_ke` 等在默认预算内未命中紧凑结构；
- 原因归类为：超出当前算子搜索复杂度 / 局部最优 / 预算不足。

> 失败案例是符号回归系统的**诚实产出**，SRBench 体系下不存在“全恢复”的系统。FeynmanForge 的相对优势体现在**恢复率显著高于朴素单目标 GP 与经典基线**（消融 +40pp）。

## 3. 公平性 / 偏差

- 纯数学拟合器，不直接处理敏感属性；输入变量的语义由使用者定义。
- 恢复的表达式可能出现在训练分布外外推失稳（外推性是符号模型的固有局限）。

## 4. 环境与碳足迹

- 纯 CPU 推理/训练，无需 GPU；demo 单轮 ≤ 60s。
- 无大规模训练，碳足迹可忽略。

## 5. 使用约束

- 恢复阈值 `recovery_r2=0.9999` 为严格近似判据；实际部署可按需放宽。
- 外推预测前建议用领域知识校验表达式的物理合理性。
